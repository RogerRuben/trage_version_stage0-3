# HV idle repositioning method

The implemented Milestone-2 idle setting uses an `Empirical Idle Repositioning
Proxy`.  It is a scenario proxy for empty movement, not a recovered true driver
cruising trajectory.

O1 and O3 combine HV repositioning and AV rebalancing as a joint idle-management
package.  They should not be interpreted as separately identifying HV-only and
AV-only effects.
