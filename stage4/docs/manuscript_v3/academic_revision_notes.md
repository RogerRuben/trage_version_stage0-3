### 主要处理

- 标题聚焦 instantaneous effective matching capacity，去掉冗长的技术副标题。
- Introduction 按混合车队、灵活资源、服务条件、本文问题组织文献，取消段尾链接串和防御式贡献辩解。
- frozen interface 改为有明确指代的 network representation / information and admission assumptions；不反复提醒“冻结”。
- gate 改写为具体的 acceptance、route compatibility、information requirements、pickup deadline，不给所有环节另造一个总称。
- fallback 在有必要的地方写成 primary / alternative route selection，明确它对未知分类和可用路线的影响。
- 不再叙述研究分支关闭、下一阶段授权、版本流水线或工程验收；这些管理记录仍由原仓库报告保存。
- 补充 E/Q/C 的数学定义与单位、mid-distribution 的取值规则和 categorical capability assumptions；依据现有代码说明，未改变计算方法。
- 四张数值结果表增加可独立阅读的 caption，数值和比较基准不变。
- 对 main result、fixed-state mechanism、timing sensitivity、network-information limitation 分别陈述证据范围，避免每段都重复全部限制。
- Declarations 保留待作者确认项，不虚构数据公开许可、伦理批准、经费或作者贡献。
