# Comparison and decision protocol

状态：**纸面设计，未执行真实数据比较，未授权下一阶段。** 本轮只完成九项有限合成核验。

## 1. 比较对象与共用权限

所有策略共用当前车辆、订单、原服务路线、候选弧、online/session 状态、hard/evidence/acceptance/pickup gates，以及场景启用的 Gamma。不得为了某策略增加候选车、重定位、改变等待、重选路线或放松资格。

首先讨论 A-strict：前三项词典序计数与最小 aggregate pickup 全部固定。A-bounded 是另一个待授权协议，不与 strict 混报；Delta_P 保持符号化。已有 optional cost 层不在本轮基础模型中启用，不能静默重排。

未来总 OD/time 和服务时长假设一致。信息比较仅切换兼容构成是否可见；方法比较必须让所有方法看到相同兼容信息。计算预算也须一致并预先固定，不能拿更强信息、更大搜索空间和更多算力共同造成的差异包装为算法优势。

## 2. 策略定义

| 策略 | 输入 | 选择与并列规则 | 本例输出 |
| --- | --- | --- | --- |
| P0 myopic | 当前完整状态，不见 p | 保持即时目标；固定 identity 次序；另报告反向次序敏感性 | 固定 x_A 或 x_H，不挑有利一侧 |
| P1-fixed | 同 P0 | 可行并列中 AV-first；不是故意劣化 baseline | x_A，未来值 1+p |
| P1-aligned | 当前状态、相同 OD/time、p | 简单规则 p≥1/2 选 x_A，否则 x_H；等号固定 x_A | 精确 V* |
| P2 blind lookahead | 当前状态及 OD/time，不见 p 或其代理 | 同一有限两动作计算框架，使用事前固定对称兼容先验；价值并列用同一 identity 规则 | 固定动作；可另列固定 q=1/2 的对称随机参照 |
| P3 aware lookahead | 与 P1-aligned 相同，包含 p、不含 W | 精确比较两动作期望；并列规则同 P1-aligned | 精确 V* |

所有输出都是当前 assignment，不是主动空驶动作。表中 p、对称先验和固定 q 仅定义合成参照，不是拟合出的生产参数。

为隔离信息效应，P2/P3 使用相同两动作枚举、目标与预算，只替换兼容分布输入。P2 的对称先验是明确的缺失信息处理，不可被表述为所有 blind lookahead 的最优代表。两个环境都报告，防止选择性比较。随机版本的 q 跨环境固定，不能事后随真实 p 改动。

## 4. 若用户以后授权，先区分四种无收益原因

1. 无行动空间：A-strict 唯一解，任何价值函数都无法改变动作。
2. 表示或模型问题：近似聚合遗漏位置/session/释放/累计 exposure，或重复计算可用车辆。
3. 近似失败：信息有价值，但价值估计或求解不能利用。
4. 简单规则足够：同信息规则已等于或接近精确参照，不需要复杂模型。

不能发现第一种就自动放宽 pickup；不能发现第四种就不断扩模型制造差距。本轮属于第四种，同时证明了有限例子中的信息价值。

若未来另行批准有限真实诊断，优先记录 strict 可选动作空间、同订单是否真的换车、下一释放位置/时间差异和决策时点可得的兼容信息。然后才判断是否有必要设计同信息方法比较。本文件不指定试跑数量、日期或新阈值，也不授权读取评估未来。

## 5. 后续评价对象与止步条件

当前状态条件下的词典序计数、pickup 秒、动作差异，与演化后的总完成服务、等待、patience expiry、车时必须分开。状态轨迹不同就不能宣称“每期与原策略服务数不变”。当前 maximum matching 也不直接等于全天完成量。
