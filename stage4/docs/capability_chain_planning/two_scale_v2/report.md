## 4. 价值层不是摆设，也不是完整未来最优解

4次更新均可用；40轮保持联合策略，没有价格不可用降级。共建立9,078个预测节点和13,208条固定稀疏接续，更新一次三情景而非每车／每当前选项各复制一遍。最终单情景649／575／593列、1,780／1,524／1,548非零元；当前流最大885动作、2,954残量边。

小型数学检查证明同一个预测客户受共享容量限制，不能分别给两辆车都记一份服务收益；零供给状态由同一客户价格定价。状态位置投影到已有20个历史地点，仅用于估值，**不作为车辆实际位置或通行证书**。记录到的投影查询13.66%距最近地点超过2km，这体现粗层聚合近似，不触发实际路线资格删除。

本次价值LP使用最多6轮列生成。**最终三情景均未达到完整定价闭合**，因此只可称“有限列、受限预测域的竞争调整价格近似”。不能称所有未来路径LP最优、真实容量边际或全城市上界。没有为了使它显示闭合而追加轮数／调参。

30轮被选动作的续行价值增量合计为负、2轮为正，说明确实传入机会损失／增益；这并不独立证明联合策略优于当前服务优先，仍需原定比较。
