# 两层方案A：接入与一次原生短窗

## 方法

每300秒用既有10/17/24日历史预测情景、冻结M3服务P50和共同需求地点建立一份稀疏未来规划图。位置投影到已有20个历史地点，预测可用与停止接单时间分别向上／向下取300秒格；未来客户取一次固定300秒上车格，不改变真实订单时间。

预测图最多三次服务，每个客户最多三条固定接续。未来空驶采用已有M3预测时长除以OD直线距离得到的分时段近似速度：不重新拟合，不用包含闲置间隔的旧RT速度，不查假想有向路线。允许等待至后续速度时段；在固定价格、位置和停止接单时间下，提前可用不会降低价值。

稀疏线性规划同时限制粗状态供给与每个预测客户的共享容量，避免每辆车都把同一个未来订单计入收益。有限列生成产生客户价格；用同一价格给有供给和零供给查询状态估值。它是受限预测域的近似，不是全城市容量上界，不承诺未来一定完成这些订单。定价最多6轮、20,000列／150,000非零元，三情景合计墙钟预算5秒；预算不足明确退回当前服务优先，不用缺失值制造路线UNKNOWN。

每30秒只有真实可执行的接单、等待和当前调位参与整数容量流。临界订单优先不变；联合策略依次优化临界服务、当前服务加续行价值、当前服务数量、当前延期订单数量。续行价值按1/3个服务机会量化，不要求最后一米距离的全局最优。

调位仍每900秒、2km范围、Top3、最长300秒、共享上限50。先用零耗时到达目的地的续行价值上界筛掉不优于等待的选项，再查真实路线、能力和方向，再按真实到达时间复算。未经真实验证的提案不进入动作流。预算到期跳过可选调位，已验证接单保留；真实数据／物理错误不隐藏。

当前固定协议关闭全局Gamma和平台成本；该流不是其他带耦合预算策略的通用替代品。BUSY和未上线车辆只作为粗层供给，不作为当前动作资源。预测使用已承诺任务的M3及剩余时长模型，不读真实服务结束或未来Test31请求。
