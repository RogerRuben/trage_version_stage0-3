## 3. 指标与解释在执行前固定

主要比较同一条件下的

\[
U_C=\frac{\sum_{v\in C}L_v}{H_C},\qquad
\Delta U_C(q,s)=U_C^{joint}(q,s)-U_C^{compatible}(q,s).
\]

\(L_v\)为载客活动与该单元可接单窗口及本地日历日交集的小时数；\(H_C\)为同一日历日的C可接单车时。跨规模必须报告这个比率，而不只比较C总订单数。承诺后完成可延至窗口之外，但那部分不计入上述分子。

共同报告：C完成订单及载客小时、全队完成订单/过期单、HV完成订单、C/HV空驶与调位距离、C从未获服务比例、上线至首单接单与首次载客（失败窗口保留）、首单前后未占用小时、实际车时、运行耗时和峰值内存。首单后的条件样本会改变，不把其均值自动解释为续单因果效应。

结论不设“联合必须获胜”的阈值：若C利用率改善但全队服务/空驶变差，报告运营取舍；若仅原种子改善，报告分配敏感；若只在某车时水平改善，报告规模条件性。不能补种子、换窗口、放宽能力或耐心使结果转正。

这是同一天、两个类型分配种子、三个车时水平的有限确认，不是多日随机试验；不报告由六次运行虚构的显著性或跨城市普遍性。规模效应仅在原种子上比较，不能把不完整交叉设计当成可识别的种子×规模交互估计。
