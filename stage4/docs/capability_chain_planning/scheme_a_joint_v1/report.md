## 4. 解质量：不是“代码能跑”而已

有限主问题采用共同第一动作和完整后继链列；精确前缀/任务集合支配压缩保留该声明域的科学目标，不采用Top-K截断后再称完整域。

整数服务目标使用可认证的有理数网格锁定，显式HiGHS可行性容差1e−9、gap为0；返回动作及情景路径由输入独立重建。LP只锁定服务目标之前已取得的临界目标；服务保留控制还锁定先行的当前/延期服务目标。**不把整数期望服务最优值自身锁进LP，制造必然0差距。**

LP上界由IEEE对偶乘子转为精确有理数后，经稀疏约束和变量界构造有效对偶上界，四例分别为精确7/2、7/2、3、3。与整数服务值一致，给出同域服务最优证据。一般实例仍可能有松弛差，不能从这四例推断LP总是整数。

空驶为服务目标后的次级目标。当其系数可安全整数化时，锁定并稳定打平；否则作为最后的数值目标，不增加浮点目标面锁定，也不声称精确距离网格最优。不会为稳定排序改变已经认证的服务目标。

六项必要检查通过（0.98秒）：独立小实例穷举与生产解比较、布局及三单接续/车型连接、共同调位与等待竞争、临界保护和上界条件、浮点误差拒绝，以及历史参考/原截止接口。定向compileall和diff check通过，没有新审计Gate。
