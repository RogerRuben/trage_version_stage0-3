## 4. 可规模化的限制链主方法

历史情景只读10/17/24已有M3 P50模板，倍率3、固定种子20261004；300秒更新稳定身份、1800秒预测视野，30秒重新选择共同当前动作。已出现真实待单保留原身份和300秒截止；预测任务不进入真实队列。真实载客耗时只有环境在承诺后读取。

先用空间索引、零接驾时间下界、任务／车型／乘客资格筛选，再查询必要有向连接。每一步最多3个客户候选／3个调位点、beam2、每当前选项／情景最多保留2条非空后继链；每链最多3项未来客户、2项未来调位。空后继隐式允许。

后继可以包含SERVICE→MOVE→SERVICE，不把独立调位当客户。当前与未来调位都保持900秒时点、2公里、300秒ETA、每时点50次的共同约束。仅模型选定的当前MOVE进入原生执行，没有另外自动贪心调位。

当前客户只服务一次；在每个情景中，当前已选SERVE与其他后继链也共享客户容量。每个资源选择一个共同当前动作，情景链必须依附该动作。主模型精确保留全部共享行分解，不能把全局调位配额在分解时丢掉。

保护当前服务：临界立即服务 → 当前服务 → 当前延期客户服务 → 当前加期望未来链服务 → 空驶。

联合控制：临界立即服务 → 当前加期望未来链服务 → 当前服务 → 当前延期客户服务 → 空驶。

整数求解只对调用方提供的受限列域最优；候选链搜索及全局列预算都是声明的近似，不给全城全链上界。若列预算不足，用固定身份哈希、逐车辆轮转分配链列，不删当前真实动作，不根据成绩选择截断。不会静默退回下一单模型。
